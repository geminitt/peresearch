## Does the corpus hold an answer? (ZetokRAG's best reranker score)

Each query is run twice: as is, and with its relevant documents removed. AUROC = chance that the answerable run scores higher. The threshold for a corpus is set on all *other* corpora so that 90% of their answerable queries pass; rejection = unanswerable runs below it, false rejection = answerable runs below it.
